# 文件粉碎工具 v2.0

一个类似360文件粉碎机的 Windows 强制删除工具，带图形界面，支持拖拽、智能删除、多轮重试、深度占用分析。

## 功能特性

- 🖱️ **拖拽操作**：将文件或文件夹拖入窗口即可添加
- 🧠 **智能模式**：动态选择删除策略，根据错误类型自动调整，最多3轮重试
- ⚠️ **强力模式**：绕过安全护栏，删除顽固文件（需二次确认）
- 🔓 **关闭句柄**：自动查找并关闭占用文件的远程句柄
- 💀 **终止进程**：查找并终止占用文件的进程树
- 🔑 **夺取所有权**：自动获取文件所有权和完全控制权限
- 🔄 **重启删除**：所有方法失败后，登记下次重启时删除
- 🔨 **粉碎覆写**：删除前用随机数据覆写文件内容，不可恢复
- 📊 **详细日志**：实时显示每一步的操作和结果
- 🛡️ **安全护栏**：自动拦截系统目录、盘根目录等危险目标

## 删除级别（L0-L6）

| 级别 | 方法 | 说明 |
|------|------|------|
| L0 | 清除属性 | 移除只读/隐藏/系统属性 |
| L1 | POSIX删除 | 使用 FILE_DISPOSITION_POSIX_SEMANTICS |
| L2 | 常规删除 | DeleteFile / RemoveDirectory |
| L3 | 夺取所有权 | takeown + 赋权后删除 |
| L4 | 关闭句柄 | NtQuerySystemInformation 枚举句柄并关闭 |
| L4.5 | NtDeleteFile | 原生 NT API 直接删除 |
| L4.6 | DELETE_ON_CLOSE | 打开时标记关闭即删 |
| L4.7 | 卸载内存映射 | NtUnmapViewOfSection 卸载被映射的DLL |
| L5 | 终止进程 | Restart Manager 查找占用进程并终止进程树 |
| L6 | 重启删除 | MoveFileEx 登记下次重启时删除 |

## 智能模式工作原理

智能模式模拟了"AI助手式"的删除策略：

1. **动态策略**：不是固定按L0→L6顺序执行，而是根据每一步的错误类型选择最合适的下一种方法
2. **多轮重试**：每种方法最多重试3次，完整方法链最多执行3轮
3. **即时反馈**：每一步的结果和错误都实时记录
4. **组合攻击**：夺取所有权后立刻尝试POSIX删除，关句柄后立刻尝试NtDeleteFile等

## 使用方法

### 直接运行
双击 `文件粉碎工具.exe` 即可启动。

### 从源码运行
```bash
pip install PySide6
python main.py
```

### 打包成exe
```bash
pip install pyinstaller
pyinstaller --onefile --noconsole --name "文件粉碎工具" --clean main.py
```

## 安全说明

- 工具默认启用安全护栏，会拦截系统目录（`C:\Windows`）、盘根目录、用户目录等
- 强力模式会绕过护栏，请确认目标安全后再使用
- 粉碎覆写功能会永久破坏文件内容，不可恢复
- 终止进程功能可能导致相关程序异常退出，请谨慎使用
